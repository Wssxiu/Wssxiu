# 引入：Zettelkasten 核心工作流全景图
Zellelkasten Workflow被总结为三个层级和四个步骤。
流程的本质：收集信息和灵感，处理为一种标准化的、可连接的“知识积木”，再用积木搭建出想要的成果。

# 怎么做Zettelkasten型的笔记
1. **Feeling notes** ：存于inbox，处理后删除
2. 筛选信息并记入 permanent notes （永久笔记）和biliographical notes （文献笔记）
3. 笔记类型
- literature notes（文献笔记）—— 归入reference system（参考文献系统）
	- 要标注页码和阅读时的要点， 重点在于用自己的话转述
	- 笔记的另一面记录完整的文献出处信息
- **Zettels**（永久笔记、卡片笔记）——每条永久笔记只包含一个独立观点
	- 用完整句子撰写并附上精准的参考文献，需要结合已有笔记的上下文
	-  永久笔记的***组织方式***：
		 - 若新笔记是对旧笔记的回应，或某个概念的很好的例子-> directly add behind the precious note
		 - 若无明显reference -> ①add links to other notes ；②创建index（包含几个进入笔记系统的入口点即可）
- Overview Notes：用于涵盖某个主题，充当该主题的Index
-  Summery Notes：用于概括一组相关笔记的核心内容
